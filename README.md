# Agentic AI Engineering

AI agent’larının tasarımı ve mühendisliği üzerine öğrenirken tuttuğum Türkçe çalışma notları. Context, memory, tools, coding agents, evaluation ve multi-agent collaboration konularını kapsıyor.

Notlar; kitaptan doğrudan alıntılar, çeviriler ve özetlerin yanında kişisel açıklamalar ve örnekler içerir. Çalışma notları niteliğindedir; model, araç ve API davranışları zamanla değişebileceğinden uygulama öncesinde güncel kaynakları kontrol edin.
